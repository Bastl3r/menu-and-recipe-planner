# Wochenplaner
Eine installierbare, deutschsprachige PWA zum Verwalten von Rezepten, Planen der Woche und Erstellen einer anpassbaren Einkaufsliste.

## Funktionen
- Rezepte mit Beschreibung, Basis-Portionenzahl und Zutaten in metrischen Einheiten pflegen
- Rezepte für bestimmte Tage mit frei wählbarer Portionszahl und Reichweite einplanen
- Zutatenmengen automatisch skalieren und als Einkaufsliste zusammenfassen
- Einkaufsmenge und Einheit anpassen und die Liste als PNG exportieren
- Anwendungsstand als JSON exportieren/importieren und über einen vierstelligen Peer-Code zwischen Geräten synchronisieren
- Offline nutzbar; Peer-Synchronisierung benötigt eine Internetverbindung

## Installation

Die Anwendung über einen statischen Webserver oder GitHub Pages bereitstellen und `index.html` öffnen. Anschließend lässt sie sich über die Browser-Einstellungen installieren.
